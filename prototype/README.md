# النموذج التفاعلي · Prototype

`index.html` — النموذج الحيّ لكَفيت: الشاشات، والسيناريوهات الخمسة، ومحرك القرار الشفّاف. ملف واحد ذاتي الاكتفاء يعمل دون إنترنت (الخطوط محلية في `fonts/`).

**التشغيل:** افتح `index.html` في المتصفح، أو `python3 -m http.server` من جذر المستودع ثم `/prototype/index.html`.
